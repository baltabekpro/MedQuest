# 🚀 Быстрый справочник: Новые функции MedQuest v2.0.0

## 1️⃣ Google OAuth
**Где:** Страница входа  
**Что делает:** Вход через аккаунт Google  
**Как использовать:** Нажмите кнопку "Вход с аккаунтом Google" на странице входа  

---

## 2️⃣ Двухфакторная аутентификация (2FA)
**Где:** Мой профиль → Безопасность  
**Что делает:** Добавляет второй уровень безопасности  
**Как использовать:**  
1. Перейдите в "Мой профиль"
2. Найдите "Двухфакторная аутентификация"
3. Нажмите "Включить"
4. Выберите способ верификации (SMS/Email/Authenticator)

---

## 3️⃣ AI-Маршрутизатор
**Где:** Левая навигация → "AI-Маршрутизатор"  
**Что делает:** Определяет нужного врача по жалобе пациента  
**Как использовать:**  
1. Введите жалобу пациента (например: "Болит голова")
2. Нажмите "Определить специалиста"
3. Система предложит врача

---

## 4️⃣ Avatar
**Где:** В профиле пользователя  
**Что делает:** Показывает инициалы пользователя в цветном круге  
**Как выглядит:** Первая буква имени и фамилии (например: "С" для администратора)  

---

## 5️⃣ Детальный профиль пациента
**Где:** Пациенты → Выберите пациента → Просмотр  
**Что показывает:**  
- Полные данные пациента
- Дата рождения, пол, группа крови
- История запросов
- Аллергии и хронические заболевания

---

## 6️⃣ Расписание (Schedule)
**Где:** Левая навигация → "Расписание"  
**Что показывает:** Календарь приёмов врачей  
**Функции:**  
- Просмотр по неделям/месяцам/дням
- Создание новых приёмов
- Планирование видеоконсультаций

---

## 7️⃣ Видеоконференция
**Где:** Расписание → Видеоконсультация  
**Что делает:** Встроенная видеосвязь между врачом и пациентом  
**Преимущества:**  
- HD качество
- Нет необходимости в отдельных приложениях
- Общий экран для демонстрации результатов

---

## 8️⃣ Чат
**Где:** Левая навигация → "Чат"  
**Что делает:** Текстовая переписка между пользователями  
**Возможности:**  
- Личные чаты (1 на 1)
- Групповые обсуждения
- История сообщений
- Интеграция с видеозвонками

## 💡 Советы для первого использования

1. **Начните с AI-Маршрутизатора** - Это самая интересная функция
2. **Включите 2FA** - Для безопасности аккаунта
3. **Изучите чат** - Быстрый способ связаться с коллегами
4. **Используйте расписание** - Для планирования видеоконсультаций
5. **Посмотрите профиль пациента** - Полная информация в одном месте
