# Обновление MedQuest v2.0.0 - Резюме

## 📝 Что было добавлено в документацию

Документация [DIPLOMA_DOCUMENTATION.md](DIPLOMA_DOCUMENTATION.md) была обновлена новым разделом **"Новые функции в обновлении"** со следующими функциями:

### ✨ Новые функции (8 функций)

1. **Google OAuth** - Вход через аккаунт Google для удобства пользователя
2. **Двухфакторная аутентификация (2FA)** - Повышенная безопасность доступа к аккаунту
3. **AI-Маршрутизатор** - Автоматическое определение специалиста на основе жалобы пациента
4. **Avatar** - Персональное изображение пользователя с инициалами
5. **Детальный профиль пациента** - Полная информация и история взаимодействия пациента
6. **Расписание (Schedule)** - Календарь приёмов врачей и видеоконсультаций
7. **Видеоконференция** - Встроенная видеосвязь для удалённых консультаций
8. **Чат** - Система обмена сообщениями между пользователями системы
